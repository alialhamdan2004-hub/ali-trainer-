# موقع علي حسين حمدان الخليف

موقع شخصي بصفحة واحدة (One Page) لمدرب رياضي متخصص في التأهيل. مبني بـ HTML/CSS/JS بسيط، بدون أي باك إند، وجاهز للنشر مباشرة.

## هيكل الملفات

```
موقع علي/
├── index.html          → هيكل الصفحة (الأقسام)، عادة لا تحتاج تعديل
├── config.js            → كل النصوص والروابط ← عدّل هنا فقط
├── css/style.css        → التصميم والألوان
├── js/main.js           → البرمجة (تعرض محتوى config.js في الصفحة تلقائياً)
├── images/               → كل صور الموقع
└── README.md            → هذا الملف
```

## 1) كيف أعدّل النصوص؟

افتح ملف **config.js** بأي محرر نصوص (حتى Notepad يكفي). كل قسم في الموقع له جزء واضح بالملف:

- `hero` → قسم البداية (الاسم، العنوان، الاقتباس، زر إنستقرام)
- `about` → قسم "من أنا" (النبذة، النقاط السريعة)
- `services` → قسم "خدماتي" (أضف/احذف خدمة بنسخ أو حذف عنصر `{ ... }` كامل داخل `items`)
- `certifications` → قسم "الشهادات" (أضف شهادة جديدة بنفس طريقة `services`)
- `contact` → قسم "تواصل معي" الختامي
- `footer` → نص أسفل الصفحة

غيّر أي نص بين علامتي التنصيص `" "` واحفظ الملف. لا تحذف الفواصل `,` ولا الأقواس `{ } [ ]`.

## 2) كيف أغيّر الصور؟

1. ضع صورتك الجديدة داخل مجلد **images**.
2. افتح **config.js**:
   - لصورتك الشخصية: غيّر السطر `profileImage: "images/profile-placeholder.svg"` إلى اسم صورتك، مثلاً `profileImage: "images/profile.jpg"`.
   - لصورة الشهادة: داخل `certifications > items`، غيّر السطر `image: "images/certificate-placeholder.svg"` إلى اسم صورتك، مثلاً `image: "images/certificate-visbody.jpg"`.

حالياً الصور الموجودة (`profile-placeholder.svg` و `certificate-placeholder.svg`) هي صور مؤقتة فقط تشرح مكان كل صورة — استبدلها بصورك الحقيقية.

## 3) كيف أغيّر الروابط (إنستقرام / تيك توك / الجوال)؟

كلها داخل **config.js** في قسم `social` أعلى الملف:

```js
social: {
  instagramUrl: "https://instagram.com/a77__1",
  tiktokUrl: "https://tiktok.com/@a_al5lef",
  phoneNumber: "", // عبّي هذا الحقل لاحقاً وسيظهر رقم الجوال تلقائياً في قسم "تواصل معي"
}
```

## 4) كيف أغيّر الألوان؟

افتح **css/style.css**، أول قسم بالملف اسمه `:root` فيه كل الألوان معرّفة مرة واحدة:

```css
--color-primary: #ff5a1f;   /* اللون البرتقالي المميز */
--color-secondary: #17c3b2; /* اللون التركوازي الثانوي */
--color-bg: #0b0d10;        /* الخلفية الأساسية */
```

غيّر قيمة أي لون هنا وسيتحدث كل الموقع تلقائياً.

## 5) كيف أجرب الموقع على جهازي؟

فقط افتح ملف **index.html** بأي متصفح (دبل كلك عليه). ما يحتاج أي تثبيت أو سيرفر.

## 6) كيف أرفع الموقع على الإنترنت (استضافة مجانية)؟

أسهل طريقة هي **Netlify Drop** (بدون حساب GitHub):

1. ادخل [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد **موقع علي** بالكامل وأفلته في الصفحة
3. بعد ثوانٍ يعطيك رابط مباشر جاهز (مثل `your-site.netlify.app`) — هذا الرابط تحطه في بايو انستقرام وتيك توك

### لرفع أي تعديل جديد لاحقاً:

- إذا رفعت الموقع بنفس طريقة Netlify Drop: عدّل الملفات، ثم روح لنفس المشروع في Netlify واسحب المجلد المُحدَّث مرة ثانية (Deploy جديد بنفس الرابط).
- إذا ربطت المشروع بحساب GitHub لاحقاً (لـ Vercel أو GitHub Pages أو Netlify عبر Git): يكفي `git add` ثم `git commit` ثم `git push`، والموقع يتحدث تلقائياً بنفس الرابط.

## ملاحظات مهمة

- الموقع بالكامل بالعربية واتجاه RTL، ولا يحتاج أي باك إند أو قاعدة بيانات.
- الخط المستخدم هو Cairo من Google Fonts (يحمّل تلقائياً عبر الإنترنت).
- الموقع متجاوب بالكامل مع الجوال والتابلت وشاشات الكمبيوتر.
